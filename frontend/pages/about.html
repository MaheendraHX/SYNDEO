SYNDEO — Intelligent Skill & Collaboration Management System

Object-Oriented Programming Project · KTU · Group 8

01 / PROJECT ABSTRACT

The idea and its purpose

SYNDEO is an Intelligent Skill & Collaboration Management System intended to connect students, professionals, freelancers, mentors, and organizations through shared competencies, interests, goals, and availability. In academic and professional environments, fragmented skill discovery and ineffective networking can make it difficult to find compatible collaborators. SYNDEO addresses this challenge through profiles that describe skills, areas of interest, practical experience, and availability.

The project aims to support purpose-driven collaboration, including study groups, project teams, mentorship networks, and professional associations. By bringing skill-related information and collaboration activities into one system, SYNDEO seeks to make team formation and peer-to-peer knowledge sharing more structured.

The application uses Java and Spring Boot for backend services and business logic, with HTML, CSS, and JavaScript for its web interface. MySQL provides relational data storage. The schema organizes users, profiles, skills, interests, circles, projects, memberships, and tasks relationally, targeting Third Normal Form (3NF). The backend uses JDBC through Spring's JdbcTemplate, Java collections for application data, and exception handling for API errors.

The project is developed on Windows using Visual Studio Code and is accessed through a web browser.

02 / CURRENT IMPLEMENTATION

What the application currently supports

The backend and web interface currently include account registration and sign-in, authenticated profile loading and editing, profile discovery with search and filters, circle membership, project membership, and project task creation and updates. Profile photos are stored in the current browser and are not uploaded to the server. Circle tags are not persisted because the database schema has no tags field.

Discovery currently lists eligible active profiles and applies profile search and filters; it does not calculate or rank recommendations. The database contains a recommendation-log schema, but a recommendation engine and recommendation API are not implemented.
