01 / The idea

Good work can begin with a conversation.

Sometimes you have a subject you keep coming back to. Sometimes you have a useful skill, but no project to put it toward. SYNDEO’s purpose is to help students explore where those starting points might meet.

This page describes what the project is intended to help with; it does not promise that every capability is already available.

02 / A possible path

From curiosity

These are the ideas that shape SYNDEO—not claims about a finished feature set.
